# Проверочный запуск

Данные получены командой:

```bash
go run ./cmd/relaylab experiment -seed 42 -runs 30 -trials 10000 -out examples/reference
```

Четыре сценария, 30 прогонов на каждый, 10 000 снимков сообщений в прогоне.
Всего разыграно 1 200 000 состояний мира; каждое использовано для пяти стратегий.
Это 1 200 000 общих снимков, а не пять независимых выборок такого размера.

| Сценарий | availability, % | risk_aware, % | Разность, п.п. |
|---|---:|---:|---:|
| shared_failure | 78,73 | 87,62 | +8,89 |
| independent_failures | 91,06 | 87,70 | -3,36 |
| weak_alternative | 78,88 | 78,88 | 0,00 |
| wrong_labels | 78,75 | 78,75 | 0,00 |

Точные, неслучайные значения находятся в `exact.csv`. Небольшое расхождение
с ними обусловлено конечным числом случайных испытаний. Расчётные
bootstrap-интервалы и парные разности находятся в `summary.csv`.

Повторный запуск с теми же параметрами в той же среде дал побайтово
идентичные пять файлов результата. Платформа и версия Go указаны в манифесте.
Смена платформы или версии Go меняет манифест; для произвольных будущих
версий генератора побайтовая идентичность не гарантируется.

Проверки исходного кода:

```bash
go test -race -cover ./...
go vet ./...
```

Обе команды выполнены успешно. Покрытие пакетов при этом запуске:
CLI 79,0%; experiment 93,3%; model 87,5%; selector 98,7%.
Покрытие показывает исполненные ветви кода, а не доказательство корректности
математической постановки или эффективности на реальной сети.

Для новой серии выбирайте `results/...`, чтобы не изменять этот контрольный
пример. Новые результаты не должны заменять старые без сохранения параметров
и версии кода.
