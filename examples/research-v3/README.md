# Проверка адаптивного метода v0.3

13 сценариев, 30 seed (1000–1029), 9 методов, 3510 расчётов. Параметры метода
фиксированы до этой серии; отдельный демонстрационный seed 42 в неё не входит.
Все условия и строки результатов получены исполняемой моделью.

Файлы:

* `runs.csv`: каждый запуск, включая отказавшие доставки и перегрузку;
* `summary.json`: средние, 95% bootstrap-интервалы и парные контрасты;
* `manifest.json`: версия, параметры, среда, число проверок и хеш конфигураций;
* `evidence-data.zip`: перечисленные данные и полный `worlds.json`;
* `delivery.svg`, `gain.svg`, `cost.svg`: фигуры, сформированные из результатов.

Сводный HTML: [docs/evidence.html](../../docs/evidence.html).
Порядок показа: [docs/proof-guide.md](../../docs/proof-guide.md).

Несколько результатов против прежнего `risk_aware`:

| Условия | Изменение доли доставки | Изменение модельного расхода |
|---|---:|---:|
| неизвестная топология и изменение качества | +64,17 п.п. [62,48; 65,72] | экономия 29,64% |
| перегрузка | +2,54 п.п. [2,37; 2,72] | экономия 2,88% |
| изменение качества при известных метках | в каждой паре доставка совпала | экономия 20,15% |
| короткий срок | средняя разность 0; интервал [-0,08; 0,08] п.п. | экономия 28,74% |
| слабая альтернатива | преимущество не установлено | расход вырос на 5,41% |

Интервалы относятся к отдельным контрастам данной модели, без одновременной
гарантии по всем сравнениям. Области полезности и отсутствия выигрыша видны
в полном отчёте. Преимущество на одном синтетическом сценарии не доказывает
превосходство над другими DTN-алгоритмами или промышленными системами.

Повторить:

```bash
go run ./cmd/relaylab research -runs 30 -seed 1000 -out results/reproduced-v3
```

Начальные оценки, модель проб и функция полезности описаны в [adaptive.md](../../docs/adaptive.md).
Прежние snapshot-эксперименты и данные временной v0.2 сохранены отдельно.
