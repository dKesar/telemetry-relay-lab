# Протокол проверок v0.3, 23 октября 2026

Go 1.27.3, linux/amd64. Измерения ниже относятся к исполнительной среде разработки.

* `go test -race -cover ./...`: пройдено.
* `go vet ./...` и сборка: пройдено.
* Покрытие ядра adaptive: 94,4%; временной модели: 95,5%.
* FuzzBudgetAndDeterminism: 150833 запуска входов за 5 секунд, нарушений не найдено.
* DOM: девять сценариев, режим кадра, график обучения, импорт/экспорт,
  отказ при испорченном журнале, три офлайн-варианта, включая комплект из пяти опытов.
* Отложенная серия: 3510 расчётов, каждый сверён с журналом сообщений.
* Повтор всей серии после оптимизации памяти дал идентичный `runs.csv`.

Это одиночные короткие измерения на INTEL XEON PLATINUM 8573C. Они иллюстрируют
удаление лишних выделений памяти и не измеряют пропускную способность сети.
Для воспроизведения: `go test ./internal/adaptive -run '^$' -bench BenchmarkChoose12 -benchmem`.

Графики экспортированы непосредственно из численных результатов в SVG, затем
преобразованы в PNG. Проверены подписи сценариев, шкалы, легенда и интервалы.
Это научные фигуры модели, не фотографии или скриншоты реального сетевого стенда.

Полная проверка layout в настоящем браузере в этой среде не подтверждена.
Для выставочного компьютера предусмотрены `tools/ui-smoke.cjs` и
`tools/capture.cjs`. Второй скрипт автоматически сохраняет пять кадров и
отчёт серии, если установлены Node.js, Playwright и Chromium. Приложению
для работы они не нужны. Порядок ручного показа: [proof-guide.md](proof-guide.md).

Тесты и покрытие не являются доказательством отсутствия всех ошибок.
Преимущество стратегии устанавливается отдельно, в пределах экспериментальной
постановки и с учётом стоимости доставки.
